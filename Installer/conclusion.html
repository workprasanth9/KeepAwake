The keepawake command line tool is installed in /usr/local/bin. Run keepawake --help or keepawake start --duration 2h to get started. Nothing runs in the background until you start a hold or run keepawake install.

If KeepAwake is useful to you, please star it on GitHub and share it with a Mac admin friend. It really helps, and it keeps the updates coming.
